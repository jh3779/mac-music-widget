## 남은 검증과 범위

실제 설치·제목/이미지 표시·Music 일시정지/복원 확인은 **1.2.2** 기록입니다. 이번 **1.2.3** 수정은 코드·fixture·빌드 검증이며, 사용 중인 설치 앱과 Safari 설정은 교체하지 않았습니다.

일반 YouTube 실제 재생, 이전/다음, AppIntent 버튼 직접 클릭, 여러 프로필, Spotify/Apple Music 실제 회귀, 장시간 WidgetKit 갱신은 기존 수동 확인 항목입니다. 자동 CI가 이를 대신하지 않습니다. 사이트의 곡 정보와 미디어 리소스는 원자적으로 바뀌지 않으므로 전환 중 잠깐 이전 제목이 관측될 수 있습니다. 동일 요소·리소스를 이벤트 없이 조용히 재사용하는 전환은 구별할 수 없습니다. 관측 가능한 세대가 바뀐 경우 이전 세대 명령은 거절합니다.

이 범위에서 확인된 미해결 P1/P2는 없습니다. 이를 모든 사이트·모든 실행 조건에서 결함이 없다는 보장으로 해석하지 않습니다.
